# Queens_Game
# GAME PROPOSAL

## Game Title
**Unicorn Quest: The Enchanted Kingdom**

## Main Goal
The goal is to guide a customizable unicorn through four magical biomes, complete missions, collect magical objects, discover hidden keys, and recover four special treasures. The final goal is to restore magic to the entire kingdom.

## Player Controls
- **W, A, S, D** or **Arrow Keys:** Move the unicorn.
- **E:** Interact with characters, magical gates, and treasure chests.
- **I:** Open the inventory.
- **Esc:** Open the pause menu.
- On-screen buttons will also support important actions and abilities.

## Gameplay
Players begin in the Enchanted Forest and progress through four increasingly challenging biomes:

1. **Enchanted Forest:** Restore the ancient forest tree and find the Magical Emerald.
2. **Fairy Kingdom:** Restore the royal fountain and find the Royal Magic Crown.
3. **Crystal Caves:** Restore the crystal heart and find the Ancient Crystal Heart.
4. **Snowy Mountains:** Restore the frozen magic shrine and find the Frozen Magic Star.

Each biome contains a main mission, optional side missions, collectibles, magical creatures, environmental challenges, hidden keys, and treasure chests. Players must complete the main mission and unlock the next magical gate to advance. Previously unlocked biomes can be revisited.

Players can customize their unicorn's colors, mane, tail, horn, wings, and accessories. They can also name their unicorn, save multiple unicorns, and create and switch between outfits.

Collectibles are picked up automatically. Players can discover coins, crystals, flowers, and stars. Magical abilities include Flying, Magic Reveal, Speed Boost, and Protection, which can be unlocked and upgraded.

The game also includes an inventory, mini-map, background music, sound effects, pause menu, and automatic progress saving.

## Scoring
Players earn points by collecting magical objects:

- Golden Coins: **10 points**
- Magic Crystals: **25 points**
- Enchanted Flowers: **50 points**
- Magic Stars: **100 points**

Hazard obstacles subtract 2 points per collision. Points cannot fall below zero.

Crystals, flowers, and stars can also be used to unlock new biomes and upgrade abilities. Golden Coins are kept permanently and are not spent.

## Win/Lose Rules
**Winning:** Players complete all four main missions, discover all four hidden keys, unlock the treasure chests, and restore the kingdom's magic. The ending transforms the four biomes into brighter, more colorful magical environments and rewards the unicorn with a special Royal Guardian Crown.

Players can continue exploring after winning.

**Losing:** There is no permanent losing condition or health system. Players can continue their adventure even after encountering obstacles.

## First Version
The first version will be a playable browser game made using **HTML, CSS, and JavaScript**, suitable for publishing on GitHub Pages.

It will focus on:
- A customizable unicorn and a playable character.
- A top-down camera and keyboard movement.
- Four connected biomes with increasing difficulty.
- Collectibles, scoring, obstacles, and simple missions.
- Magical keys, treasure chests, and gates.
- Basic character interactions and inventory.
- A simple mini-map and pause menu.
- Basic magical abilities.
- Automatic saving using browser localStorage.
- A completed ending and the ability to keep exploring.

Additional features will be introduced in later updates, including advanced unicorn management, multiple saved outfits, detailed ability upgrades, customizable interface layouts, seasonal theme creation, shareable character cards, and a community theme gallery.

The community gallery will initially use built-in themes and downloadable theme files. A live online sharing system would require additional technology beyond the original static website.

**Technology:** HTML, CSS, and JavaScript only. No paid services, login system, backend, database, or secret API keys are required for the first version.
